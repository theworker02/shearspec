# shearspec

Shear structured JSON spec payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/shearspec/

## Install / run

```bash
git clone https://github.com/theworker02/shearspec.git
cd shearspec
node src/cli.js
node --test
```
